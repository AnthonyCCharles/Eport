Here are some of my projects.

  • Barbershop Booking App

    React, Tailwind CSS, Firebase Auth, Cloud Firestore

    A full-stack appointment booking app for a barbershop. Guests sign in with one click, pick a service, day and open time slot, and manage or cancel their bookings. Firestore transactions and security rules make double-booking impossible, even if someone edits the code in their browser.

  • Loadout — E-commerce Store

    React, Tailwind CSS, Stripe, Vercel Serverless Functions

    A gaming gear store with search, category filters, price sorting and a cart that stays saved after a refresh. Checkout runs through real Stripe Checkout (test mode) using a serverless function that looks up prices on the server, so they can't be changed in the browser.

  • NextFlix — Streaming App

    React, Vite, Tailwind CSS, TMDB API, Firebase Hosting

    A streaming-style browsing app with a featured hero banner, horizontally scrolling genre rows, hover cards and live search across movies and TV shows, all powered by live data from the TMDB API.

  • YouClone — Video Platform

    React, Vite, Tailwind CSS, YouTube Data API, Firebase Hosting

    A video platform with trending and category feeds, search, a collapsible sidebar and video pages, built on live data from the YouTube Data API.
